# Feedmute support site

The support page, privacy policy and site rules for Feedmute, a Safari content blocker for iPhone and iPad that hides YouTube Shorts, Instagram Reels and endless feeds.

- Support: https://woscxy.github.io/feedmute-support/
- Privacy policy: https://woscxy.github.io/feedmute-support/privacy.html
- Site rules the app downloads: `catalog/v1.json`

## Feedback

Please email cxy130434@gmail.com rather than opening an issue; issues are switched off here. In the app, **Something still showing? › Report a Site** fills in the details we need.

This repository is published from the app's source, so changes made here directly are replaced on the next update.
